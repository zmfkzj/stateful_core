# Auto-approve Stateful approval prompts

## Goal

Add an opt-in way to skip Stateful-owned OMP approval prompts, starting with `ext_rw_bash`, without weakening sandbox scope checks, hook denials, reservation/claim checks, or command confinement.

## Context

`ext_rw_bash` is generated by `crates/stateful-cli/src/install.rs`. It currently requires `ctx.ui.confirm` before creating a scoped external sandbox grant. The grant is keyed by purpose, write/create/write-dir/socket/signal/network scope and constrained by max uses and TTL. `ext_ro_bash` already runs without a UI prompt because it has no write/socket/signal scope.

## Design

Support both opt-in paths:

1. Tool-call flag: `ext_rw_bash(auto_approve: true)` skips the OMP UI grant prompt for that call.
2. Profile config: `stateful.autoApprove: true` in the OMP profile config skips Stateful-owned approval prompts for the profile.

The generated extension will add a small helper that returns true when either source is enabled. `ext_rw_bash` will use that helper before checking `ctx.ui.confirm`; when auto-approval is enabled, it will record the same external grant metadata the manual approval path records, then run the existing sandbox command path.

## Safety boundaries

Auto-approval only replaces the OMP UI confirmation for Stateful-owned prompts. It does not bypass:

- `stateful sandbox run --fs external` scope validation
- repo-relative write reservation and claim requirements
- hook deny decisions
- raw Bash/eval denials
- external grant keying by purpose and declared scope
- grant max uses and expiry

Raw command text remains hidden from grant prompts. With auto-approval there is no prompt to display.

## Tests

Use the existing install-output tests in `crates/stateful-cli/tests/install_global.rs` because the OMP tool is generated as JavaScript text. Add assertions that the generated extension contains:

- `auto_approve` in the `ext_rw_bash` schema
- `stateful.autoApprove` config lookup
- a branch that skips `ctx.ui.confirm` when auto-approval is enabled
- grant recording still shared with the manual path
